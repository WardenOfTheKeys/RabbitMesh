A small update to RabbitMesh 0.1.0.

## Which file

| File | Flash at | When |
|---|---|---|
| `rabbitmesh-0.1.1-tdeck-update.bin` | `0x10000` | **Already on RabbitMesh:** this one. Keeps your settings, contacts and identity. Don't erase first. |
| `rabbitmesh-0.1.1-tdeck-full.bin` | `0x0` | First install, coming from any other firmware (it resets the settings; back up first). |

Flash with the [Espressif web flasher](https://espressif.github.io/esptool-js/) in Chrome or Edge: hold the trackball while switching the T-Deck on, plug it in, connect at 921600, add the file at its address, Program. New to RabbitMesh? See the [README](https://github.com/WardenOfTheKeys/rabbitmesh#readme).

## What's new

- **WiFi + BT wardrive: addresses in the live view.** Each network or device in the latest-seen list now shows its MAC address under its name, with the channel for WiFi, the way the flock hunt shows a camera's. A Bluetooth device on a random address (most phones, for privacy) is marked `(random)`: that address changes, it isn't the device's own.
